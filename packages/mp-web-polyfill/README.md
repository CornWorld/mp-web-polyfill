# mp-web-polyfill

微信小程序逻辑层 Web API polyfill 家族:`fetch` / `EventSource` / `URL` / `TextEncoder` / `localStorage` / `FormData`,附一站式全局安装器。

```bash
pnpm add mp-web-polyfill
```

子路径导出、用法、真机差异与体积数据见[仓库文档](https://github.com/CornWorld/mp-web-polyfill#readme)。
